# Epic status

The authoritative per-story status, verification evidence, external blocks, and next prerequisites live in [docs/story-status.md](docs/story-status.md).

Current release target: private Windows-local Phase A. Live broker/provider/device acceptance and Phase B forecasting/options automation require separately documented external access or licensed data and are not inferred from fixture coverage.

Use these meanings consistently:

- **Implemented** — code is present through a normal entry point.
- **Verified** — stated acceptance behavior has direct test or local-run evidence.
- **Blocked External** — a named credential, provider entitlement, dataset, or device check is missing.
- **Deferred by Scope** — retained Phase B work, not a Phase A completion claim.
